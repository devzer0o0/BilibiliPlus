## 2. 逐图说明

### hero-night-watch.webp

- **素材类型**：原创二次元场景插画，README 首屏横幅；**不是应用截图**。
- **生成方式**：在仓库外用本地 HTML/CSS/SVG 绘制「深夜书桌与拱窗」场景，Chrome headless 以 2× 渲染后由 `cwebp -q 88` 转码。未调用任何在线生图服务，未上传私有内容。

- **未使用**：仓库内 `docs/images/readme/anime-art/` 下的另一批位图素材（来路与本轮制作无关）未被引用，也未被改动。
- **作者 / 工具**：本轮为 PiliPlus README 绘制；Chrome headless、cwebp。
- **字体**：使用本机系统字体（Avenir Next、PingFang SC）渲染，仓库不分发字体文件。
- **授权**：本轮原创插图，随本 README 按仓库 GPL-3.0 提供；图中文案在正文中均有对应文字说明。
