## 2. 逐项说明

### hero-prologue.webp

- **素材类型**：原创横版二次元插画，作为 README 首屏横幅使用；**不是应用截图**。
- **生成方式**：本任务在仓库外用本地 HTML/CSS 绘制场景，使用 Chrome headless 以 2× 尺寸渲染，再由 `cwebp -q 88 -metadata none` 转为 WebP。未调用生图服务，未上传任何私有内容。
- **画面元素**：原创动画角色、金色小电视（项目既有图标母题的再绘制）、玻璃卡片、云与星点。没有使用知名动漫角色、第三方吉祥物或外部图库素材。
- **作者 / 工具**：本任务为 PiliPlus README 绘制；Chrome headless、cwebp。
- **字体**：由本机系统字体（Avenir Next、Hiragino Sans GB、PingFang SC）渲染；仓库不嵌入、不分发字体文件。
- **授权**：本任务原创插图，随本 README 按仓库的 GPL-3.0 许可提供。图中的文字信息在 README 正文中也有对应说明，关键信息不只存在于图片里。
- **截图环境**：不适用。
